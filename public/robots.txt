# One group on purpose. Under the robots standard (RFC 9309) a crawler follows
# only the single most specific group that names it, so a Content-Signal placed
# only under "User-agent: *" would never reach a bot that is also named below.
# Stacking every name in this one group gives all of them the same Allow and
# the same signal. The named list is for legibility; "*" already covers any
# crawler not listed, and nothing needs adding when a new one appears.
#
# Content-Signal is Cloudflare's proposal, not yet a formal standard: search
# indexing, AI-answer grounding/RAG, and model training are all fine.
